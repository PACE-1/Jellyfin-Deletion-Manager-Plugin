# Security

This plugin can delete files, so please report security problems privately.

Use GitHub's "Report a vulnerability" on the Security tab of this repository. Do not open a public issue for a problem that could let someone without the right permission request, approve or run a deletion, read another user's requests, or delete something a guard should have protected.

Please include the plugin and Jellyfin versions and the steps to reproduce. You will get a reply within a few days. Only the latest release is supported.
