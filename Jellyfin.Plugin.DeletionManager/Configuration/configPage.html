Jellyfin Deletion Manager

The V1.0 Jellyfin Enhanced fork is still installed. It has its own deletion executor, so this plugin will not delete anything while the fork is loaded. Import your requests below, check the queue, then uninstall the fork and restart Jellyfin.

Import from V1.0

Copies requests and history from the V1.0 fork's database into this plugin. The V1.0 database is never changed, and importing again is safe: rows already imported are kept as they are, and a row that changed in the V1.0 database afterwards is reported, not applied. Imported requests do not run until you enable physical deletion above.
